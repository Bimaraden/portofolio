# Bima Raden Portfolio

Portfolio website for Bima Raden — Web Development, Workflow Automation, and IoT.

## Run Locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev -- --host 0.0.0.0 --port 3000`
3. Open the app in your browser at:
   `http://localhost:3000`

## Build for Production

```bash
npm run build
```
